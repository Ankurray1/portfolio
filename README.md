# Ankur Ray · Portfolio

Personal portfolio of Ankur Ray, AI Product Manager (B2B SaaS and agentic AI) and co-founder of a creative studio.

The site lets a visitor pick a track, **Product career** or **Founder**, each with its own look, timeline, projects and proof.

## What's inside

- **Product career**: experience at Vantage Circle and ADP, a career timeline, the people I've worked with, and recognition.
- **Projects**: a featured build (*I ran Claude Code inside Microsoft Copilot*) and four case studies in pop-ups:
  - Salary Revision Workflow for greytHR (PRD + prototype)
  - SubSentry (PRD + live MVP)
  - Recognition & Rewards (product thinking case study)
  - AI News Agent (personal automation, [code](https://github.com/ankurray561/ai-news-agent))
- **Certifications**: IIT Patna (Vishlesan i-Hub) and IIM Visakhapatnam.
- **Blogs**: selected LinkedIn posts.
- **Design system**: the tokens and components the site is built from.

## How it's built

- A single `index.html`: HTML, CSS and vanilla JavaScript, no build step.
- The content lives in one JSON block inside the page.
- Original PRDs and wireframes are in `docs/`. They open in an in-page PDF viewer built on [pdf.js](https://mozilla.github.io/pdf.js/).
- Built with [Claude](https://claude.ai).

## Run locally

Serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
